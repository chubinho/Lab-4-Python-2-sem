# Лабораторная работа №4. Асинхронный исполнитель задач

## Описание работы
Четвёртый этап разработки платформы посвящён реализации асинхронной модели управления. Основная цель работы — создание системы, способной эффективно обрабатывать задачи из очереди в неблокирующем режиме с использованием расширяемых обработчиков и механизмов контроля ресурсов.

Архитектура системы базируется на библиотеке `asyncio`, что обеспечивает высокую производительность и масштабируемость. В рамках работы реализовано разделение ответственности между очередью, воркером и конкретными обработчиками, связанными общим контрактом.

## Ключевой функционал
* **Асинхронная очередь задач**: Использование `asyncio.Queue` для хранения и эффективного распределения задач между воркерами.
* **Контрактное программирование (Protocol)**: Описание интерфейса `TaskHandler` через `typing.Protocol`, что позволяет реализовать структурную типизацию и легко добавлять новые типы задач.
* **Управление ресурсами**: Реализация асинхронных контекстных менеджеров (`async with`) для безопасной работы с внешними ресурсами (например, имитация подключений к базе данных).
* **Централизованное логирование**: Фиксация всех этапов жизненного цикла задачи и состояния системы.
* **Отказоустойчивость**: Изолированная обработка исключений внутри воркера — ошибка в одной задаче не приводит к остановке всего исполнителя.


## Структура проекта
```
Lab-4-Python-2-sem/
├── src/
│   ├── __init__.py
│   ├── main.py              # Точка входа (запуск event loop и воркеров)
│   ├── async_queue.py       # Обертка над asyncio.Queue
│   ├── task_worker.py       # Логика извлечения и маршрутизации задач
│   ├── handler_protocol.py  # Описание контракта TaskHandler (Protocol)
│   ├── context_managers.py  # Асинхронные контекстные менеджеры (DB, ресурсы)
│   ├── task.py              # Модель задачи (из прошлых работ)
│   ├── handlers/            # Набор конкретных обработчиков
│   │   ├── api_handler.py
│   │   ├── report_handler.py
│   │   └── logging_handler.py
│   └── logger.py            # Централизованная настройка логирования
├── tests/
│   ├── test_worker.py       # Тестирование асинхронного цикла и воркеров
│   ├── test_handlers.py     # Тесты логики отдельных обработчиков
│   └── test_async_queue.py  # Тесты асинхронной очереди
├── requirements.txt
└── README.md
```
